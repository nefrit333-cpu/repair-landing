# Repair Landing

Учебный mobile-first лендинг для частного прораба с командой. Тематика проекта - ремонт квартир под ключ в Москве в разумном ценовом сегменте, без премиального пафоса и без выдуманных доказательств.

Сайт сделан как портфолио-демо. Это не страница реального подрядчика: имя, фото, кейсы, отзывы и документы показаны как структура, которую можно заменить на настоящие данные клиента.

## Что есть в проекте

- адаптивная вёрстка с приоритетом на мобильную версию;
- компактный header и бургер-меню на мобильных экранах;
- первый экран с оффером, CTA и быстрыми фактами;
- раскрывающиеся блоки для примеров расчёта, этапов контроля, этапов работы и FAQ;
- форма заявки с frontend-валидацией;
- видимые ошибки формы и заметный статус успешной отправки;
- честные demo/placeholder-блоки вместо фейковых отзывов, документов и кейсов;
- коммерческая структура лендинга: боли клиента, доверие, цены, сроки, гарантии и финальная форма;
- визуальная полировка под портфолио: спокойная строительная палитра, аккуратные карточки, сильнее первый экран и mobile-first подача.

## Что отработано

В этом проекте отработаны не только HTML/CSS/JS, но и приёмка результата после генерации ИИ-кода:

- постановка задачи для ИИ под конкретную нишу;
- коммерческий аудит лендинга;
- честная работа с demo-контентом без фальшивых доказательств;
- mobile-first UI и проверка адаптива;
- визуальная доводка лендинга без перехода в премиальный люкс;
- бургер-меню и доступные состояния открытия;
- раскрывающиеся списки без перегруза страницы;
- проверка формы: пустая форма, успешная отправка, сброс полей;
- подготовка проекта к публикации как портфолио-кейса.

## Структура файлов

```text
repair-landing/
├─ index.html
├─ styles.css
├─ script.js
└─ README.md
```

`index.html` содержит разметку страницы: шапку, первый экран, блоки доверия, проблемы, решение, услуги, сроки, примеры расчёта, цены, FAQ и форму.

`styles.css` отвечает за визуальный стиль: цвета, шрифты, фон, сетки, карточки, кнопки, форму, mobile-адаптив, hover/focus-состояния и бургер-меню.

`script.js` отвечает за поведение: плавный переход к форме, открытие и закрытие мобильного меню, клиентскую валидацию формы, ошибки и статус успешной отправки.

## Как открыть локально

В папке проекта запусти простой локальный сервер:

```bash
python -m http.server 4177 --bind 127.0.0.1
```

Затем открой в браузере:

```text
http://127.0.0.1:4177/
```

Если Python недоступен, можно открыть `index.html` напрямую. Но через локальный сервер проверка ближе к обычной публикации сайта.

## Как проверить форму

1. Нажми `Получить предварительную смету`.
2. На пустой форме нажми `Рассчитать примерную смету`.
3. Убедись, что появились ошибки у всех обязательных полей.
4. Заполни имя, телефон, тип квартиры, площадь и описание задачи.
5. Нажми кнопку ещё раз.

Ожидаемый результат: ошибки исчезают, появляется статус `Спасибо. Данные приняты, можно передавать заявку на расчёт.`, а поля очищаются.

Форма работает только на стороне браузера. Она не отправляет заявку на сервер и не сохраняет данные.

## Что заменить для реального клиента

Перед коммерческим запуском нужно заменить demo-части на реальные данные:

- имя и фото прораба;
- опыт, состав команды и районы работы;
- реальные кейсы с разрешёнными фотографиями;
- настоящие отзывы клиентов;
- реальные примеры смет, чек-листов и документов;
- актуальные цены и состав работ;
- рабочую отправку формы: backend, CRM, почту или другой канал;
- согласие на обработку персональных данных, если форма собирает контакты.

## Ограничения

- нет backend;
- форма не отправляет заявку на сервер;
- demo-контент не является реальными доказательствами;
- фотографии взяты как demo/stock-визуалы для учебного проекта и не являются реальными объектами конкретного прораба;
- цены и сроки показаны как ориентиры и требуют проверки под конкретного подрядчика.

## Чему учит этот кейс

Проект показывает, как превратить сгенерированный ИИ лендинг в более аккуратный учебный кейс: проверить форму, усилить мобильную версию, убрать фейковые доказательства, честно подписать demo-блоки и привести страницу к виду, который можно показать в портфолио.
